def fibonacci(n):
    """Calculate the nth Fibonacci number using dynamic programming."""
    if n <= 1:
        return n
    
    fib = [0] * (n + 1)
    fib[1] = 1
    
    for i in range(2, n + 1):
        fib[i] = fib[i-1] + fib[i-2]
    
    return fib[n]

class BinarySearchTree:
    def __init__(self, value):
        self.value = value
        self.left = None
        self.right = None
    
    def insert(self, value):
        if value < self.value:
            if self.left is None:
                self.left = BinarySearchTree(value)
            else:
                self.left.insert(value)
        else:
            if self.right is None:
                self.right = BinarySearchTree(value)
            else:
                self.right.insert(value)

## Advanced Programming Patterns
Implementing a thread-safe singleton pattern in Python requires careful attention to race conditions. The classic double-checked locking pattern can be implemented using threading.Lock() to ensure only one instance is created even in multithreaded environments. Here's a robust implementation using a metaclass:

class SingletonMeta(type):
    _instances = {}
    _lock = threading.Lock()
    
    def __call__(cls, *args, **kwargs):
        if cls not in cls._instances:
            with cls._lock:
                if cls not in cls._instances:
                    instance = super().__call__(*args, **kwargs)
                    cls._instances[cls] = instance
        return cls._instances[cls]

## Operating System Internals

## Advanced Programming Patterns
Implementing a thread-safe singleton pattern in Python requires careful attention to race conditions. The classic double-checked locking pattern can be implemented using threading.Lock() to ensure only one instance is created even in multithreaded environments. Here's a robust implementation using a metaclass:

class SingletonMeta(type):
    _instances = {}
    _lock = threading.Lock()
    
    def __call__(cls, *args, **kwargs):
        if cls not in cls._instances:
            with cls._lock:
                if cls not in cls._instances:
                    instance = super().__call__(*args, **kwargs)
                    cls._instances[cls] = instance
        return cls._instances[cls]

Async generators allow streaming data processing without loading entire datasets into memory.

## Database Query Optimization
Analyzing SQL query execution plans reveals bottlenecks. Index usage dramatically improves SELECT performance when filtering on indexed columns. However, indexes slow INSERT/UPDATE operations and consume additional storage. Composite indexes benefit queries filtering on multiple columns, but column order matters—place most selective columns first.

SELECT u.name, COUNT(o.id) as order_count
FROM users u
LEFT JOIN orders o ON u.id = o.user_id
WHERE u.created_at > '2024-01-01'
GROUP BY u.id, u.name
HAVING COUNT(o.id) > 5
ORDER BY order_count DESC
LIMIT 100;

## Cryptography Fundamentals
RSA encryption relies on computational difficulty of factoring large semiprimes. Public key (n, e) encrypts: c = m^e mod n. Private key (d) decrypts: m = c^d mod n. Key generation selects large primes p, q computing n=p*q and φ(n)=(p-1)(q-1).

AES operates on 128-bit blocks with key sizes 128, 192, or 256 bits. The cipher performs multiple rounds of substitution, permutation, mixing, and key addition. CBC mode chains blocks using XOR with previous ciphertext, requiring unique IVs.

## Compiler Theory
Lexical analysis tokenizes source code into terminal symbols. Regular expressions define token patterns matched by finite automata. Context-free grammars describe syntax parsed into abstract syntax trees.

LL parsers predict productions using lookahead tokens. LR parsers build parse tables from grammar states, handling left-recursive grammars. Type checking ensures expression types match their usage contexts. Semantic analysis resolves identifiers and validates program semantics.

Code generation translates ASTs to intermediate representations like three-address code. Register allocation assigns variables to limited hardware registers using graph coloring. Optimization passes include constant folding, dead code elimination, loop unrolling, and inline expansion.

## Operating System Internals
Virtual memory pages map logical addresses to physical frames via page tables. Translation lookaside buffers cache recent translations for performance. Page faults trigger on-demand loading from disk. Working set algorithms predict frequently accessed pages.

Process scheduling algorithms balance throughput and latency: FIFO is simple but unfair, round-robin provides time slicing, shortest job first minimizes average wait time, priority scheduling serves high-priority tasks first. Multilevel feedback queues dynamically adjust priorities based on behavior.

Deadlock occurs when processes circularly wait for resources. Prevention requires breaking circular wait, hold-and-wait, no preemption, or mutual exclusion conditions.

def fibonacci(n):
    """Calculate the nth Fibonacci number using dynamic programming."""
    if n <= 1:
        return n
    
    fib = [0] * (n + 1)
    fib[1] = 1
    
    for i in range(2, n + 1):
        fib[i] = fib[i-1] + fib[i-2]
    
    return fib[n]

class BinarySearchTree:
    def __init__(self, value):
        self.value = value
        self.left = None
        self.right = None
    
    def insert(self, value):
        if value < self.value:
            if self.left is None:
                self.left = BinarySearchTree(value)
            else:
                self.left.insert(value)
        else:
            if self.right is None:
                self.right = BinarySearchTree(value)
            else:
                self.right.insert(value)

## Advanced Programming Patterns
Implementing a thread-safe singleton pattern in Python requires careful attention to race conditions. Here's a robust implementation using a metaclass:

class SingletonMeta(type):
    _instances = {}
    _lock = threading.Lock()
    
    def __call__(cls, *args, **kwargs):
        if cls not in cls._instances:
            with cls._lock:
                if cls not in cls._instances:
                    instance = super().__call__(*args, **kwargs)
                    cls._instances[cls] = instance

Implementing a thread-safe singleton pattern in Python requires careful attention to race conditions. class SingletonMeta(type):
    _instances = {}
    _lock = threading.Lock()
    
    def __call__(cls, *args, **kwargs):
        if cls not in cls._instances:
            with cls._lock:
                if cls not in cls._instances:
                    instance = super().__call__(*args, **kwargs)
                    cls._instances[cls] = instance

## Advanced Programming Patterns
Implementing a thread-safe singleton pattern in Python requires careful attention to race conditions. The classic double-checked locking pattern can be implemented using threading.Lock() to ensure only one instance is created even in multithreaded environments. Here's a robust implementation using a metaclass:

class SingletonMeta(type):
    _instances = {}
    _lock = threading.Lock()
    
    def __call__(cls, *args, **kwargs):
        if cls not in cls._instances:
            with cls._lock:
                if cls not in cls._instances:
                    instance = super().__call__(*args, **kwargs)
                    cls._instances[cls] = instance
        return cls._instances[cls]

## Advanced Programming Patterns
Implementing a thread-safe singleton pattern in Python requires careful attention to race conditions. The classic double-checked locking pattern can be implemented using threading.Lock() to ensure only one instance is created even in multithreaded environments. Here's a robust implementation using a metaclass:

class SingletonMeta(type):
    _instances = {}
    _lock = threading.Lock()
    
    def __call__(cls, *args, **kwargs):
        if cls not in cls._instances:
            with cls._lock:
                if cls not in cls._instances:
                    instance = super().__call__(*args, **kwargs)
                    cls._instances[cls] = instance
        return cls._instances[cls]

    """Calculate the nth Fibonacci number using dynamic programming."""
    if n <= 1:
        return n
    
    fib = [0] * (n + 1)
    fib[1] = 1
    
    for i in range(2, n + 1):
        fib[i] = fib[i-1] + fib[i-2]

The learning rate hyperparameter controls step size—too large causes oscillation, too small leads to slow convergence. Adam optimizer adapts learning rates per parameter using moving averages of gradients and squared gradients.

Backpropagation computes gradients through the chain rule:
∂L/∂w = ∂L/∂y * ∂y/∂z * ∂z/∂w

Regularization techniques prevent overfitting: L1 (Lasso) encourages sparsity, L2 (Ridge) penalizes large weights, Dropout randomly disables neurons during training. Batch normalization stabilizes training by normalizing layer inputs.

## Network Programming
TCP provides reliable byte streams with flow control and congestion avoidance. The three-way handshake establishes connections: SYN, SYN-ACK, ACK. Window scaling negotiates buffer sizes for high-bandwidth networks. Nagle's algorithm reduces small packet overhead by buffering data.

WebSocket maintains persistent bidirectional connections over HTTP:
const ws = new WebSocket('wss://api.example.com/stream');
ws.onopen = () => ws.send(JSON.stringify({type: 'subscribe', channel: 'updates'}));
ws.onmessage = (event) => {
    const data = JSON.parse(event.data);
    console.log('Received:', data);
};

gRPC uses HTTP/2 multiplexing for efficient RPC with protocol buffers providing compact binary serialization.

## Cryptography Fundamentals
RSA encryption relies on computational difficulty of factoring large semiprimes. Public key (n, e) encrypts: c = m^e mod n. Private key (d) decrypts: m = c^d mod n. Key generation selects large primes p, q computing n=p*q and φ(n)=(p-1)(q-1).

AES operates on 128-bit blocks with key sizes 128, 192, or 256 bits. The cipher performs multiple rounds of substitution, permutation, mixing, and key addition. CBC mode chains blocks using XOR with previous ciphertext, requiring unique IVs.

## System Design Principles
Microservices architecture decomposes monoliths into independently deployable services. Each service owns its data store, communicating via APIs or message queues. Service mesh handles cross-cutting concerns: retry logic, circuit breakers, distributed tracing, mutual TLS.

Load balancers distribute traffic using round-robin, least connections, or consistent hashing algorithms. Health checks automatically remove failing instances. Horizontal scaling adds capacity by deploying more replicas. Stateless services simplify scaling—session data moves to Redis or databases.

Eventual consistency accepts temporary inconsistency for availability and partition tolerance (CAP theorem). CQRS separates read and write models for performance optimization.

## Compiler Theory
Lexical analysis tokenizes source code into terminal symbols. Regular expressions define token patterns matched by finite automata. Context-free grammars describe syntax parsed into abstract syntax trees.

LL parsers predict productions using lookahead tokens. LR parsers build parse tables from grammar states, handling left-recursive grammars. Type checking ensures expression types match their usage contexts. Semantic analysis resolves identifiers and validates program semantics.

Code generation translates ASTs to intermediate representations like three-address code. Register allocation assigns variables to limited hardware registers using graph coloring. Optimization passes include constant folding, dead code elimination, loop unrolling, and inline expansion.

## Operating System Internals
Virtual memory pages map logical addresses to physical frames via page tables. Translation lookaside buffers cache recent translations for performance. Page faults trigger on-demand loading from disk. Working set algorithms predict frequently accessed pages.

Process scheduling algorithms balance throughput and latency: FIFO is simple but unfair, round-robin provides time slicing, shortest job first minimizes average wait time, priority scheduling serves high-priority tasks first. Multilevel feedback queues dynamically adjust priorities based on behavior.

Deadlock occurs when processes circularly wait for resources. Prevention requires breaking circular wait, hold-and-wait, no preemption, or mutual exclusion conditions.

## Quantum Computing Basics
Qubits exist in superposition of |0⟩ and |1⟩ states: |ψ⟩ = α|0⟩ + β|1⟩ where |α|² + |β|² = 1. Measurement collapses superposition to definite states. Entanglement creates correlations stronger than classical physics permits.

Quantum gates manipulate qubits: Hadamard creates superposition, CNOT entangles pairs, Pauli X/Y/Z perform rotations. Grover's algorithm searches unsorted databases in O(√N) time. Shor's algorithm factors integers exponentially faster than classical methods, threatening RSA security.

## Climate Modeling
General circulation models simulate atmosphere-ocean dynamics using Navier-Stokes equations discretized on 3D grids. Parameterization approximates sub-grid processes like cloud formation and turbulence. Coupled models integrate atmosphere, ocean, cryosphere, and biosphere components.

Radiative forcing quantifies climate drivers: CO₂ absorption at 15μm wavelengths traps infrared radiation. Feedback loops amplify or dampen warming: ice-albedo feedback accelerates polar melting, water vapor feedback increases humidity. Climate sensitivity measures equilibrium warming from doubled CO₂, estimated at 3°C ± 1.5°C.

def fibonacci(n):
    """Calculate the nth Fibonacci number using dynamic programming."""
    if n <= 1:
        return n
    
    fib = [0] * (n + 1)
    fib[1] = 1
    
    for i in range(2, n + 1):
        fib[i] = fib[i-1] + fib[i-2]
    
    return fib[n]

    def __init__(self, value):

        self.right = None

        if value < self.value:

        else:
            if self.right is None:
                self.right = BinarySearchTree(value)
            else:
                self.right.insert(value)

## Advanced Programming Patterns
Implementing a thread-safe singleton pattern in Python requires careful attention to race conditions. The classic double-checked locking pattern can be implemented using threading.Lock() to ensure only one instance is created even in multithreaded environments. Here's a robust implementation using a metaclass:

class SingletonMeta(type):
    _instances = {}
    _lock = threading.Lock()
    
    def __call__(cls, *args, **kwargs):
        if cls not in cls._instances:
            with cls._lock:
                if cls not in cls._instances:
                    instance = super().__call__(*args, **kwargs)
                    cls._instances[cls] = instance
        return cls._instances[cls]

When handling multiple concurrent requests, Promise.all() can execute them in parallel while maintaining error handling through try-catch blocks. Async generators allow streaming data processing without loading entire datasets into memory.

## Database Query Optimization
Analyzing SQL query execution plans reveals bottlenecks. Index usage dramatically improves SELECT performance when filtering on indexed columns. However, indexes slow INSERT/UPDATE operations and consume additional storage. Composite indexes benefit queries filtering on multiple columns, but column order matters—place most selective columns first.

SELECT u.name, COUNT(o.id) as order_count
FROM users u
LEFT JOIN orders o ON u.id = o.user_id
WHERE u.created_at > '2024-01-01'
GROUP BY u.id, u.name
HAVING COUNT(o.id) > 5
ORDER BY order_count DESC
LIMIT 100;

Quantum gates manipulate qubits: Hadamard creates superposition, CNOT entangles pairs, Pauli X/Y/Z perform rotations. Grover's algorithm searches unsorted databases in O(√N) time. Shor's algorithm factors integers exponentially faster than classical methods, threatening RSA security.

## Climate Modeling
General circulation models simulate atmosphere-ocean dynamics using Navier-Stokes equations discretized on 3D grids. Parameterization approximates sub-grid processes like cloud formation and turbulence. Coupled models integrate atmosphere, ocean, cryosphere, and biosphere components.

Radiative forcing quantifies climate drivers: CO₂ absorption at 15μm wavelengths traps infrared radiation. Feedback loops amplify or dampen warming: ice-albedo feedback accelerates polar melting, water vapor feedback increases humidity. Climate sensitivity measures equilibrium warming from doubled CO₂, estimated at 3°C ± 1.5°C.

def fibonacci(n):
    """Calculate the nth Fibonacci number using dynamic programming."""
    if n <= 1:
        return n
    
    fib = [0] * (n + 1)
    fib[1] = 1
    
    for i in range(2, n + 1):
        fib[i] = fib[i-1] + fib[i-2]
    
    return fib[n]

class BinarySearchTree:
    def __init__(self, value):
        self.value = value
        self.left = None
        self.right = None
    
    def insert(self, value):
        if value < self.value:
            if self.left is None:
                self.left = BinarySearchTree(value)
            else:
                self.left.insert(value)
        else:
            if self.right is None:
                self.right = BinarySearchTree(value)
            else:
                self.right.insert(value)

## Advanced Programming Patterns
Implementing a thread-safe singleton pattern in Python requires careful attention to race conditions. The classic double-checked locking pattern can be implemented using threading.Lock() to ensure only one instance is created even in multithreaded environments. Here's a robust implementation using a metaclass:

class SingletonMeta(type):
    _instances = {}
    _lock = threading.Lock()
    
    def __call__(cls, *args, **kwargs):
        if cls not in cls._instances:
            with cls._lock:
                if cls not in cls._instances:
                    instance = super().__call__(*args, **kwargs)
                    cls._instances[cls] = instance
        return cls._instances[cls]

## Database Query Optimization
Analyzing SQL query execution plans reveals bottlenecks. Index usage dramatically improves SELECT performance when filtering on indexed columns. However, indexes slow INSERT/UPDATE operations and consume additional storage. Composite indexes benefit queries filtering on multiple columns, but column order matters—place most selective columns first.

SELECT u.name, COUNT(o.id) as order_count
FROM users u
LEFT JOIN orders o ON u.id = o.user_id
WHERE u.created_at > '2024-01-01'
GROUP BY u.id, u.name
HAVING COUNT(o.id) > 5
ORDER BY order_count DESC
LIMIT 100;

The query planner evaluates multiple execution strategies: nested loop joins, hash joins, or merge joins depending on table sizes and available indexes. Materialized views cache expensive aggregations for read-heavy workloads.

## Cryptography Fundamentals
RSA encryption relies on computational difficulty of factoring large semiprimes. Public key (n, e) encrypts: c = m^e mod n. Private key (d) decrypts: m = c^d mod n. Key generation selects large primes p, q computing n=p*q and φ(n)=(p-1)(q-1).

AES operates on 128-bit blocks with key sizes 128, 192, or 256 bits. The cipher performs multiple rounds of substitution, permutation, mixing, and key addition. CBC mode chains blocks using XOR with previous ciphertext, requiring unique IVs.

## Operating System Internals

## Advanced Programming Patterns
Implementing a thread-safe singleton pattern in Python requires careful attention to race conditions. The classic double-checked locking pattern can be implemented using threading.Lock() to ensure only one instance is created even in multithreaded environments. Here's a robust implementation using a metaclass:

class SingletonMeta(type):
    _instances = {}
    _lock = threading.Lock()
    
    def __call__(cls, *args, **kwargs):
        if cls not in cls._instances:
            with cls._lock:
                if cls not in cls._instances:
                    instance = super().__call__(*args, **kwargs)
                    cls._instances[cls] = instance
        return cls._instances[cls]

Composite indexes benefit queries filtering on multiple columns, but column order matters—place most selective columns first.

## Cryptography Fundamentals
RSA encryption relies on computational difficulty of factoring large semiprimes. Public key (n, e) encrypts: c = m^e mod n. Private key (d) decrypts: m = c^d mod n. Key generation selects large primes p, q computing n=p*q and φ(n)=(p-1)(q-1).

AES operates on 128-bit blocks with key sizes 128, 192, or 256 bits. The cipher performs multiple rounds of substitution, permutation, mixing, and key addition. CBC mode chains blocks using XOR with previous ciphertext, requiring unique IVs.

## Operating System Internals
Virtual memory pages map logical addresses to physical frames via page tables. Translation lookaside buffers cache recent translations for performance. Page faults trigger on-demand loading from disk. Working set algorithms predict frequently accessed pages.

Process scheduling algorithms balance throughput and latency: FIFO is simple but unfair, round-robin provides time slicing, shortest job first minimizes average wait time, priority scheduling serves high-priority tasks first. Multilevel feedback queues dynamically adjust priorities based on behavior.

Deadlock occurs when processes circularly wait for resources. Prevention requires breaking circular wait, hold-and-wait, no preemption, or mutual exclusion conditions.

def fibonacci(n):
    """Calculate the nth Fibonacci number using dynamic programming."""
    if n <= 1:
        return n
    
    fib = [0] * (n + 1)
    fib[1] = 1
    
    for i in range(2, n + 1):
        fib[i] = fib[i-1] + fib[i-2]
    
    return fib[n]

class BinarySearchTree:
    def __init__(self, value):
        self.value = value
        self.left = None
        self.right = None
    
    def insert(self, value):
        if value < self.value:
            if self.left is None:
                self.left = BinarySearchTree(value)
            else:
                self.left.insert(value)
        else:
            if self.right is None:
                self.right = BinarySearchTree(value)
            else:
                self.right.insert(value)
